## 🧠 Key Concepts

### Decision Trees and Information Gain

Information gain helps decision trees choose better features for splitting data.  
A feature with higher information gain reduces uncertainty more effectively and creates purer child groups.

### Equal Information Gain

If two features have the same information gain, either feature can be selected.  
A simple tie-breaking rule, such as choosing the first feature checked, can be used.

### Linear Regression and Outliers

Linear regression is sensitive to outliers because it minimizes squared errors.  
Large errors receive more weight, so an outlier can strongly affect the regression line.

### Correlation vs Regression

Correlation measures the strength and direction of a relationship between two variables.  
Regression builds a predictive equation that can estimate one variable using another.
